## 0️⃣ U-P2-1 前置：AGC 控制台创建 ChatSessionRecord 对象类型

> 只影响 P2-7d 联调（§4）；不做本步时 §1–§3、§5 可先行验收。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) → 我的项目 → 本项目；
2. 左侧 **构建 → 云数据库**：若首次进入，先确认已有存储区（课程同步在用的那个 Cloud Zone 即可，无需新建）；
3. **对象类型** 页签 → 添加/导入对象类型 → 选择仓库文件 `CloudProgram/clouddb/objecttype/ChatSessionRecord.json` 导入（或按该 JSON 手动录入字段）；
4. 核对导入结果：
   - 字段五项：`id`(String，**主键**) / `userId`(String) / `payload`(Text) / `payloadVersion`(Integer) / `updatedAt`(Date)；
   - 权限仅 Authenticated / Creator / Administrator 三种角色，**无 World**；
   - 索引两条：userId、userUpdated(userId+updatedAt)；
5. 保存并校验通过即可（端侧模型类 `pages/CloudDb/ChatSessionRecord.ets` 已手写，无需再从控制台导出 ts 文件）。

## 1️⃣ P2-7a 云端自动同步（课程+考试）

| # | 操作 | 预期 |
|---|---|---|
| A1 | 设置页开启「云端自动同步」，保持 WiFi | 开关持久化；退出设置页重进仍为开 |
| A2 | WiFi 下修改任一课程（如改教室），≤30s 后在 AGC 控制台 云数据库 → 数据管理 查 ClassCourse | 记录 updatedAt/内容为最新值；设置页「上次自动同步成功」时间刷新 |
| A3 | 连续快速改动同一门课多处 | 30s 内合并为一轮上传（日志一轮），不逐次触发 |
| A4 | 断网（关模拟器网络）改一门课 → 恢复网络 | 恢复后 ≤1 分钟内补传成功；期间无崩溃 |
| A5 | 关闭「云端自动同步」后改课程数据 | 云端零变化（观察数据管理页无新写入） |
| A6 | 关 WiFi 用蜂窝流量（且不开蜂窝子开关）改数据 | 本轮跳过并有日志；开启「允许蜂窝网络同步」后可上传 |

## 2️⃣ P2-7b 条目级 LWW 下载合并

前置：双实例均已开自动同步，且各自手动完成一次基线上传。

| # | 操作 | 预期 |
|---|---|---|
| B1 | 实例 A 新增一门课并上传 → 实例 B 点「从云端合并」 | B 出现该课，原有课不变 |
| B2 | **双写冲突**：断 A 网络 → B 改某课教室并上传 → A 改同课另一字段后恢复网络 → B 再合并 | 两端最终一致显示 updatedAt 较新一方的值；设置页「同步状态」出现该条裁决（胜负+原因） |
| B3 | 构造时间戳相等（同秒双写难构造可跳过或用同设备时钟对齐近似） | 相等时云端胜，日志原因「时间戳相等，云端优先」 |
| B4 | A 删除某课并上传 → B 合并 | B 仍保留该课（无删除墓碑的预期行为，非 bug） |
| B5 | 冲突反复制造多次 | 同步状态列表最多显示 5 条、日志总量封顶 50 条，超出裁最旧 |

## 4️⃣ P2-7d AI 会话加密上云（依赖 U-P2-1）

| # | 操作 | 预期 |
|---|---|---|
| D0 | 未建表前开启「AI 会话云同步」开关 | 仅 `[SessionSync]` warn 日志软降；App 功能无感、不崩溃 |
| D1 | 未登录状态看设置页该行 | 置灰不可操作；登录后可用 |
| D2 | 登录 + 建表后新增/修改会话，WiFi 下等 ~15s | 云端出现对应 ChatSessionRecord 记录；**payload 列肉眼不可读（密文）** |
| D3 | AGC 控制台查看 payload 字段 | 全部为 base64 密文，无明文标题/消息内容泄漏 |
| D4 | 删除本地某会话 → 下轮同步 | 云端对应记录被裁剪消失 |
| D5 | 会话数堆到 20 上限后继续新建 | 本地裁剪至 20，云端同步后同样 ≤20 |
| D6 | 实例 B 登录同账号开开关 | B 拉取到 A 的会话（解密正常入列表）；两端列表一致 |
| D7 | 人为向云端塞一条损坏 payload（可选） | 该条跳过并记日志，其余会话正常合并 |
| D8 | 蜂窝未开子开关 | 本轮跳过有日志（与 A6 同门控） |
| D9 | 退出登录后再改会话 | 一切 no-op；注销账号后定时器取消、密钥缓存清除 |
