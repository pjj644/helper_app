# 模拟器冒烟清单（U2 · 用户配合）

> 对应优化计划 `OPTIMIZATION_PLAN.md` 中的 **U2**：Wave 合入后，在 DevEco Studio 模拟器上逐项确认以下内容。
> 请按顺序执行，每项完成后勾选 `[ ]` → `[x]`，异常情况写入「备注」栏。

## 前置条件（一次性）

- [ ] DevEco Studio 模拟器已启动并保持在线
- [ ] 最新构建的 HAP 已安装到模拟器（entry-default）
- [ ] 本机 ai-proxy 后端已启动（`npm run dev`，监听 `:3000`），PC 与模拟器处于同一局域网网段
- [ ] 已知当前代理密钥（设置页所用 `X-Proxy-Key`）
- 备注：

## 1. 五 Tab 逐一加载正常

**操作步骤**

1. 冷启动应用，停留在默认首屏；
2. 按顺序点击底部五个 Tab：**发现 → AI助手 → 课程 → 日历 → 我的**；
3. 每个 Tab 内停留 3~5 秒，观察渲染与数据加载。

**预期结果**

- 每个 Tab 首次切入均有内容呈现（骨架屏/加载态可接受，但不允许白屏、花屏或闪退）；
- 来回切换无崩溃、无布局错乱；日志无未捕获异常刷屏。

- [ ✅] 通过
- 备注：

---

## 2. 设置页填入局域网后端地址与密钥，「测试连接」成功

**操作步骤**

1. 进入 **我的 → 应用设置**；
2. 在后端地址栏填入 PC 的局域网地址（如 `http://192.168.x.x:3000`）与对应密钥；
3. 保存配置；
4. 点击 **「测试连接」**。

**预期结果**

- 「测试连接」在数秒内返回成功提示（走 `GET /health`）；
- 故意填错地址再测一次应给出明确的失败提示（此为反向抽查，可选）。

- [✅ ] 通过
- 备注：

---

## 3. 清空配置后进入 AI 助手 → 出现「去配置」引导卡片

**操作步骤**

1. 回到设置页，清空后端地址与密钥并保存；
2. 切到 **AI助手** Tab，发起或观察对话入口。

**预期结果**

- 不弹崩溃/裸错误，而是显示**引导卡片**，明确提示“尚未配置后端”，并提供可点击的「去配置」（跳转设置页）；
- 点击「去配置」能正确跳到设置页。

- [ ✅] 通过
- 备注：

---

## 4. AI 对话：基础问答一轮 + 确认弹窗指令流程完整

**操作步骤**

1. 先恢复第 2 步的有效配置；
2. 在 AI助手发送一条基础问答（如“今天有什么课？”），等待流式回答完成；
3. 再发送一条会触发工具确认的指令（如“帮我创建一个明天早上8点的日程”）；
4. 在确认弹窗上分别验证「取消」与「确认」两条路径（可重复发一次指令）。

**预期结果**

- 基础问答有流式文本输出并以完成态收尾；
- 创建日程类指令先弹出**确认弹窗**，展示将执行的动作摘要；
- 点「取消」→ 不执行任何变更；点「确认」→ 执行成功并有结果反馈/toast；
- 全程无卡死、无重复弹窗。

- [ ✅] 通过
- 备注：
我问：“帮我创建一个明天早上8点的日程”后，调用工具ask_user_clarification向用户申请，我点击允许后显示ask_user_clarification失败，对于这种低风险的tools不用弹出确认弹窗，调整一下到底哪些tools需要用户确认，还有为什么允许后调用失败。

## 6. 添加 2x2 / 2x4 桌面卡片显示课程数据

**操作步骤**

1. 回到模拟器桌面，长按应用图标 → 选择 **服务卡片**；
2. 先后添加 **CourseWidgetCard2x2** 与 **CourseWidgetCard2x4** 两种规格到桌面；
3. 若无课程数据，先在课程 Tab 完成一次课表导入/确保存在当日课程，再回到桌面刷新观察。

**预期结果**

- 两种规格卡片均能成功添加到桌面；
- 卡片正确显示课程信息（课程名/教室/时间段等），排版无溢出、无空白块；
- 有课程变化时卡片数据可随定时/刷新更新（观感检查即可）。

- [ ✅] 通过
