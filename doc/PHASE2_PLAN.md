## 3. 任务详单

### P2-7a 云端自动同步 `[待实施]`

- **方案**：
  1. 设置页「数据同步」卡片新增独立的**「云端自动同步」开关**（与现有本地日历自动同步开关并存，互不干扰），持久化新偏好键；
  2. 课程/考试数据变更落盘后 debounce 30s 触发静默上传；频率上限最快 5 分钟一次 diff 上传（CloudDB 免费档配额护栏）；
  3. 失败指数退避；未成功条目进入本地待同步队列（preferences 落盘），下次启动与网络恢复时补传；
  4. 默认仅 WiFi 自动，蜂窝需显式开启（连接管理模块判断网络类型）。
- **涉及文件**：`SyncService.ets`、`AppSettings.ets`、`AppConstants.ets`、新增轻量 `AutoSyncScheduler`（或并入 SyncService）。
- **验证**：模拟器改课程数据 → ≤30s 云端可见；断网操作恢复后补传；开关关闭零上传。
- **提交**：`feat(sync): background auto upload with debounce queue and offline retry`

### P2-7b 条目级 LWW 下载合并 `[待实施]`

- **方案**：
  1. 下载合并从「整包覆盖」改为**条目级比较**：以 `(courseId, semesterId, dayOfWeek, startSection)` / 考试业务键对齐双端条目；
  2. 双方都有 → 比较 `updatedAt` 新者胜（本地时钟），时间戳相同再比 `deviceId` 兜底排序；仅一端有 → 按删除墓碑语义处理（本期简化：仅一端有即保留，冲突日志记录）；
  3. 服务器接收时间为最终裁决兜底（防时钟漂移）；冲突事件写本地日志，设置页「同步状态」入口可查最近 N 条。
- **涉及文件**：`SyncService.ets`（下载合并路径）、`CourseRepository.ets`/`ExamRepository.ets`（批量 upsert）、`AppSettings.ets`。
- **验证**：双模拟器实例构造双写冲突 → LWW 裁决正确；单端删除/新增场景数据一致。🔴 双实例验收留 U-P2-4。
- **提交**：`feat(sync): entry-level lww merge on download with conflict log`

### P2-7c 数据 ID 治理决策落地 `[待实施 · 先决策]`

- **背景**：hash 截断 ID 多设备并发写入理论上有碰撞风险；id-generator 云函数已存在但接入需要 AGC 控制台部署一次。
- **两个选项**：
  - **选项 1（推荐）**：写入路径改用已实现的 `generateUniqueId`（时间戳+7 位随机熵，个人使用级别碰撞概率可忽略），存量 hash ID 不迁移、惰性升级（下次变更该条时换新号）。**无需任何云函数部署**。
  - **选项 2**：接入 id-generator 云函数批量取号（本地预取缓存一批降低延迟）。🔴 需用户 AGC 控制台部署。
- **默认按选项 1 实施**；若审阅时选择选项 2，主 agent 另附部署步骤清单。
- **提交**：`feat(sync): adopt entropy-based unique ids for synced records`

### P2-7d 同步范围扩展：日程 + 加密会话 `[可选 · 视余量]`

- 日程（`schedule_data_json`）纳入同步范围，沿用 7a/7b 的队列与 LWW 机制；
- AI 会话历史上云前用账号 UID 派生密钥做对称加密，服务端只见密文；密钥丢失即历史不可读，设置页明示；
- 若实现成本超预期：降级为「默认不同步会话，设置页手动开启（明文）」，并在验收时注明。

### P2-8 小艺意图接入 `[待实施]` —— 本轮核心

- **调研结论**（详见 [`RESEARCH_XIAOYI.md`](./RESEARCH_XIAOYI.md)）：装饰器式意图（API 20+，本项目 SDK 为 API 22 ✅）允许**未上架阶段在真机本地调试验证**；真实语音触发须 AGC 上架 + 小艺开放平台注册审核，个人开发者准入官方未明文——本轮交付到「真机本地验证通过 + 准入确认邮件草稿」，上架与否留待决策。
- **首批圈定 3 个免登录只读意图**（全部复用「主 App 落盘、无 UI 组件只读 preferences」的既有架构，同桌面卡片模式）：
  1. `NextCourse`（`@InsightIntentFunction` 后台）：读课程缓存返回下一节课，`resultDesc` 中文话术「下一节课是 X，HH:MM 在 Y 教室」；无课时友好话术；
  2. `TodayExam`（`@InsightIntentFunction` 后台）：今日/最近考试列表话术；
  3. `OpenTimetable`（`@InsightIntentPage` 前台）：拉起 App 并直达课表页（DeepLink 参数化路由）。
- **实施要点**：
  1. Function 意图约束：export 类静态全局函数、参数仅基本类型、**不得参与代码混淆**（构建配置核查）；
  2. `llmDescription`/`keywords` 按「我的下一节课/下节课是什么/今天有什么考试」等口语措辞编写并预留迭代；
  3. 步骤①：先把课表/考试页路由参数化为 DeepLink 可达（`module.json5` skills 导出 uri），此步同时是未来 Link/Page 意图的原料；
  4. 步骤②③：三个意图声明 + 端侧实现；步骤④：真机意图框架调试页逐一手动执行验证（🔴 U-P2-2/U-P2-3）。
- **产出**：可用代码 + 真机验证记录（截图/录屏说明）+ hagservice@huawei.com 准入确认邮件草稿（含个人开发者资质问询与垂类开放范围）。
- **明确不在本轮**：AGC 上架流程、小艺开放平台意图注册、语音真实触发联调、A2A/MCP 试验（记入后续观察项）。
- **提交**：`feat(intent): deeplink routing for timetable pages` / `feat(intent): insight intents for next course and today exam`

### P2-9 截图导入入库前预览修正 UI `[待实施]`

- **背景**：P2-2 当前为解析结果直接入库，识别错漏无法在落库前修正（子 agent 收尾建议，原 v1.0 计划本就有此项）。
- **方案**：课表/成绩两处「截图导入」在解析完成后插入**预览确认表格**：识别条目列表（课程名/教师/教室/节次周次 或 成绩/学分/GPA）逐行可编辑，低置信度字段高亮提示，支持整行剔除；确认后才走 `CourseService`/`GradeService` 入库。复用现有导入预览组件风格，不引入新依赖。
- **验证**：故意改错一个字段保存 → 库中为修改后值；剔除某条目 → 不入库；低置信度字段正确高亮。
- **提交**：`feat(import): preview and correct vision results before saving`
